The engine

Three files.
One deterministic trailer.

Every cut is driven by three plain-JSON contracts — swap the model, rewrite the screen content, and the same camera language renders a brand-new film.

01 / CONTRACT

The model

model.manifest.json

Normalize any GLB with a screen: orientation, scale, and which mesh is the display. The engine aims every shot at the screen for you.

02 / CONTRACT

The storyboard

storyboard.json

Camera moves as spherical keyframes — push-in, orbit, crane — with fade timings. The same storyboard re-renders identically, frame for frame.

03 / CONTRACT

The screen

PTContent

A pure function of time: what the screen shows at every frame — a terminal session, an auto-scrolling landing page, anything you can draw on canvas.

Workflow

From GLB to red carpet.

No sign-up, no cloud queue. The whole pipeline runs locally and open-source.

01

Calibrate the model

Load a GLB with a screen, pick the display mesh in the browser workbench, export model.manifest.json.

02

Storyboard the shots

Write storyboard.json: camera keyframes, focal lengths, fades. Or start from a shipped example.

03

Script the screen

A PTContent template draws each frame — terminal, landing page, or your own canvas logic.

04

Render the trailer

Preview the live HTML, then export a deterministic MP4 — vertical 9:16 or horizontal 16:9.
